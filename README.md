# TUM Semester 1 Calendar

Ready for GitHub Pages.

## Publish
1. Create a PUBLIC GitHub repository named `tum-calendar`.
2. Upload all files in this folder to the repository root.
3. Go to Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`; folder: `/(root)`; Save.
6. Wait for GitHub Pages to publish, then open the site URL shown in Settings → Pages.

## Outlook
For course-by-course colors, use each course's separate `.ics` URL:
Outlook Calendar → Add calendar → Subscribe from web → paste URL.

A single `all-courses.ics` subscription is included, but Outlook will normally display that whole subscribed calendar using one calendar color.

Note: the published GitHub Pages site and `.ics` feeds are public.
